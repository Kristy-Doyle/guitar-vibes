# Guitar Vibes 🎸

**Final project for my first Full-Stack Development course** — a responsive, multi-page website built with HTML and CSS.

## 🔍 Project Overview
Guitar Vibes is a front-end website designed for beginner guitar players. It features:

- 🎵 A media page with locally hosted videos and audio
- 🎸 A guitar chord reference table
- 📄 A contact form with basic validation
- 📱 Fully responsive layout with accessibility in mind

## 🛠️ Built With
- HTML5
- CSS3 (external stylesheet)
- Basic form validation
- Accessibility best practices

## 📁 Pages Included
- `index.html` – Home page
- `about.html` – About the site
- `media.html` – Embedded audio/video & chord diagrams
- `contact.html` – Contact form

## 🚀 Future Improvements
- JavaScript for interactive features
- Dark mode toggle
- Backend form handling (PHP/Node)
